      ## 문제점 1)
			: 불용어 사전 및 사용자 사전
		  불용어
			   - 기본 불용어
			   - 유투버 이름 / 제품명 / 제품 카테고리 까지가 등록사항.
			
			-> 불용어 / 사용자정의단어 UI로 등록할 수 있도록.
				-> 등록하게 되면 반영일은 ? 
				현재는 댓글 약 2899개에 15~20분가량 걸림.
			   	배치 주기 얼마로 잡아야할지 : 데이터양에따라다름
			
			-> 
			안0): 되는대로 다음번 데이터 처리 배치에 반영(오래걸리더라도)
			안1): rank를 최대로 매기고 사용자가 삭제하는 방식으로 사용 + 다음번 배치에 해당 키워드 불용어 등록도 함.
      
      ### 문제점 2)
      : 불용어-> 모든 제품에 등록?? -> 제품 카테고리별 불용어를 생성해야할지.
      ex) 현재는 휘센 에어컨 ABCDEF -> 휘센, 에어컨, ABCDEF가 빈도수가 높은 것이 당연시, 키워드가 나타내는 의미 특징 없다고 생각해서
          불용어를 등록하도록 했음.
          사례 1) -> 다른 가전기기에 대해 그램이랑 연동이 되었으면 좋겠다는 반응이 많은데
              노트북 제품 조사때문에 그램이라는 모델명이 불용어로되어있다면
              해당 반응 못봄
                -> *** 타 제품군간 불용어 : 제품군별 불용어 지정.
                    -> 현재 제품군별로 카테고리가 안되어있어서 X (LG전자 샵에 카테고리화가 되어있긴 함)
          사례 2) -> 만약 ABCDEF모델이랑 지난 모델인 휘센 타워에어컨이 대한 반응이 대다수라면 ? ? 
            -> ex) 휘센 타워에어컨이 훨씬 낫다
              -> 유의미하다고 생각하는데 만약에 타워에어컨이 제품등록이 되어있다면
                타워에어컨은 불용어로 해당 반응 보지 못함
                -> *** 같은 제품군간 불용어 : 해결하기위해서는 자신 모델만 제외해야함,
